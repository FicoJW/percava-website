# Percava Website

A responsive multi-page website developed for Percava, focusing on product presentation, brand storytelling, and user-friendly navigation.

## Features

- Responsive multi-page website
- Product showcase and information pages
- Brand/story content
- Profile and contact sections
- Interactive elements using JavaScript
- Responsive layout for different screen sizes

## Pages

- `index.html` — Home page
- `produk.html` — Product page
- `cerita.html` — Brand/story page
- `profil.html` — Profile page
- `connect.html` — Contact/connect page

## Technologies

- HTML5
- CSS3
- JavaScript
